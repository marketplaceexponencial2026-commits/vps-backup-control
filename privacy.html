Política de Privacidade

VPS BACKUP CONTROL

Última atualização: 15 de novembro de 2026.

1. Finalidade

O VPS Backup Control é uma aplicação de uso privado, destinada ao armazenamento automatizado e à recuperação de backups de infraestrutura digital.

2. Acesso aos dados do Google

A aplicação solicita autorização para criar, consultar, editar e excluir arquivos de backup no Google Drive, utilizando o escopo drive.file.

O acesso é limitado aos arquivos criados ou autorizados para esta aplicação pelo titular da conta.

3. Utilização dos dados

Os dados acessados são utilizados exclusivamente para armazenamento, manutenção e restauração de backups.

4. Compartilhamento de dados

A aplicação não vende dados pessoais, não utiliza dados para publicidade e não utiliza dados do Google Drive para treinamento de modelos de inteligência artificial.

5. Segurança

O sistema foi projetado para utilizar backups criptografados, autenticação OAuth 2.0 e armazenamento protegido de credenciais.

6. Retenção e exclusão

A política inicial prevê a retenção de backups por 30 dias. O titular poderá excluir os backups e revogar a autorização da aplicação a qualquer momento.

7. Conformidade com as políticas do Google

O uso de informações recebidas das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de Limited Use.

8. Revogação do acesso

O titular poderá revogar as permissões concedidas nas configurações de segurança da sua conta Google.
